# Ali's Little World 💙

A responsive multi-page baby welcome website for baby Ali and mama Romesa.

## Pages
- `index.html` — 3D animated welcome/login entry page with a teddy-bear GIF
- `home.html` — main homepage
- `welcome.html` — royal welcome
- `letter.html` — personal congratulations letter for Romesa
- `gallery.html` — add baby photos locally
- `dua.html` — dua for Ali
- `wishes.html` — interactive gift-opening surprise

Every page includes a vertical **Created by Rehan Mamo** credit.

## Publish on GitHub Pages
1. Extract this ZIP.
2. Upload all files inside the `ali_baby_welcome` folder to your repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then Save.

The entry page is `index.html`. Its button opens `home.html`.

## Notes
- The entry page is a decorative welcome screen, not password-based security.
- Animated GIFs load from external image hosts and require internet access.
- Gallery photos are previewed in the current browser session and are not uploaded to a server.
- Music is an original synthesized chime and starts only after the visitor taps Music.
